# 作息规律

## 工作日

- 07:00 起床，需要轻快的音乐唤醒
- 08:30-09:00 通勤路上，听播客或轻松流行乐
- 09:00-12:00 上午工作，偏好 lo-fi / 氛围音乐帮助专注
- 12:00-13:30 午休，适合舒缓的爵士或波萨诺瓦
- 14:00-18:00 下午工作后半段，需要节奏感强的音乐提神
- 18:30-19:30 下班/晚餐，放松心情
- 20:00-23:00 晚间自由时间，可能看书、玩游戏或聊天
- 23:30 准备入睡，偏好安静的钢琴或氛围音乐

## 周末

- 上午较随意，可能睡懒觉
- 下午可能外出，或在家做家务
- 晚上可能聚会或看电影
- 深夜喜欢一个人听歌发呆

## 偏好备注

- 工作时不喜欢有人声的歌曲（纯音乐优先）
- 运动/做家务时喜欢节奏感强的歌
- 看书时需要极简的背景音
