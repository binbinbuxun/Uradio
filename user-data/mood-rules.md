# 心情与音乐映射规则

> 基于歌单全量分析（5,545 首，v3.0）。所有推荐风格均来自歌单中真实存在的高频内容。
> DJ 选曲时以本文件为"场景→风格"的路由表，结合 taste.md 中的艺人名单取材。
> 歌单是五维结构（EDM / Hip-Hop / Pop / 华语 / R&B + Alt/Indie 纵深），每个场景可能跨多个圈层取材。

---

## 🎉 高能释放 / 蹦迪 / 高强度运动 ★★★★★

**风格**：主舞台 Big Room / Progressive House、Bass / Dubstep / Riddim、🆕 Liquid DnB
**艺人**：
- 经典大舞台：Martin Garrix、Tiësto、Hardwell、David Guetta、Avicii
- Bass / Trap：Skrillex、Yellow Claw、KSHMR、Knock2、ISOxo
- 🆕 DnB 新坑：Sub Focus、Dimension（+ 延伸 Wilkinson、Koven）
**BPM**：160–180（DnB）/ 140–150（Dubstep/Riddim）/ 128–132（Big Room）
**说明**：DnB 是这个场景的"进阶档"——比常规主舞台 House 更快的鼓点，旋律性保留（非 Neurofunk 工业感）。DJ 可把 Sub Focus / Dimension 当作"运动高潮段落"的特殊武器
**避免**：华语抒情、R&B 低速曲目、任何 BPM < 110 的东西

---

## 🚗 通勤 / 公路 / 微 High ★★★★☆

**风格**：Pop-EDM 跨界、旋律 Progressive House、欧美主流 Pop
**艺人**：The Chainsmokers、Kygo、Alan Walker、R3HAB、Coldplay、Dua Lipa、Lauv、Charlie Puth
**BPM**：122–138，中高位，不需要全情投入，背景化播放友好
**说明**：有能量但不炸，旋律记忆点强。自驾可加入 Synthwave（The Midnight、M83）做"复古公路"氛围

---

## 🌙 深夜独处 / 情绪流动 ★★★★★

**风格（英语）**：情感系 Future Bass（ILLENIUM 系）、Alt-R&B（The Weeknd / SZA / Frank Ocean 系）、Synthwave / Dream Pop（The Midnight / M83）、梦幻流行（The Marías）
**风格（华语）**：华语灵魂（丁世光 / 方大同 / 陶喆）、台湾独立 / City Pop（落日飞车 / 陈绮贞 / 魏如萱）
**艺人精选**：ILLENIUM、San Holo、Said The Sky、The Midnight、The Weeknd、SZA、Frank Ocean、The Marías、丁世光、方大同、陶喆、陈绮贞、魏如萱、落日飞车
**BPM**：90–115（R&B / 华语抒情）；情绪 Future Bass 高潮可到 150
**选曲原则**：
- 这是歌单**情绪浓度最高的一块**，人声情绪浓、和声层次细腻
- The Weeknd《Dawn FM》专辑可以在这个场景整张连播
- 23:30 后进入"陪伴模式"：降能量、减冲击、换成人声驱动的情绪系曲目
- 华语权重在深夜场景最高，可以大量使用
- 近期收藏优先：The Marías、陈绮贞、魏如萱（最新补番）、RAYE

## 🎸 情绪宣泄 / 孤独自省 ★★★★☆

**风格**：Emo-Alt / 情感另类流行、艺术 Hip-Hop、Indie Rock
**艺人**：
- twenty one pilots（《Blurryface》《Vessel》时期——歌单里唯一的"乐队级真爱"）
- Billie Eilish（《WHEN WE ALL FALL ASLEEP》时期）
- The Strokes（《The New Abnormal》——不是怀旧，是被成熟近作打动）
- Kanye West（《MBDTF》选曲——偏好"有野心的专辑"）
- Tyler the Creator（《IGOR》——最接近 R&B/艺术电子的一张）
**BPM**：90–115
**说明**：这些艺人的共同质感是**歌词驱动、存在主义情绪、被听懂而非被包裹**——适合需要"某种意义上的释放出口"的时刻，而非放松。当用户表达压力、焦虑、想独处时，这个场景比"深夜情绪"更合适

## 🎵 怀旧 / 高光时刻 ★★★★★

**风格**：2010s EDM 全盛期经典（大舞台大合唱）；华语经典黄金年代
**艺人（EDM 经典）**：Avicii、Alan Walker（Faded 时期）、Tiësto、Armin van Buuren、Martin Garrix
**艺人（华语怀旧）**：周杰伦、陶喆、陈奕迅
**说明**：这批"老歌"是锚点级存在，自带"全场合唱"感。周杰伦/陶喆/陈奕迅情绪跨度大，更适合作为"情绪节点触发"而非固定场景硬塞

## ☕ 治愈 / 松弛 / 文艺 ★★★★☆

**风格**：台湾独立 / City Pop、热带浩室、华语 R&B 精品线、Daft Punk《Random Access Memories》
**艺人**：陈绮贞、魏如萱、落日飞车、告五人、甜約翰、刘柏辛 Lexie、NIKI、Kygo、Sam Feldt
**说明**：区别于"治愈=钢琴/爵士"的刻板模板——这份歌单的"治愈"是有清晰律动的 City Pop 和松弛的独立流行。落日飞车的 City Pop/Funk 质感和 Daft Punk《RAM》、HONNE 审美高度重叠

## 专注工作 / 学习 ★★☆☆☆

⚠️ **注意**：歌单中几乎不含 Lo-fi / Ambient / 极简电子，这个场景的歌单供给天然不足。
- 如果用户没有专用歌单，可尝试：**熟悉到"听不见歌词"的老歌**（已存档的 EDM 经典）、Tropical House 低调曲目（Kygo 轻量侧）、华语轻柔系（陈绮贞）
- **建议主动提醒用户**：这个电台的口味不太适合作为专注工作的主力，建议切换专用纯器乐/白噪声歌单
- 18 首电影配乐（Hans Zimmer、John Williams）是罕见的纯器乐选项，可偶尔使用

## 雨天 / 室内安静氛围 ★★★☆☆

**风格**：华语独立（陈绮贞、魏如萱）、梦幻流行（The Marías）、Synthwave（The Midnight）
**说明**：这份歌单的"雨天"不是爵士咖啡馆，而是"有情绪感的室内氛围"——带着忧郁但不抑郁，有质感但不沉闷

## 通用选曲规则

**五维取材**：歌单是五维结构（EDM / Hip-Hop / Pop / 华语 / R&B + Alt/Indie），每个场景都可能跨多个圈层取材。不要只从 EDM 取材——Hip-Hop、R&B、Alt/Indie 都有独立的场景供给能力。

**连贯性**：连续播放时保持曲风一致性，大跳跃前要串场缓冲
- **最佳桥接风格**：Future House / Bass House（124–128 BPM），是各 BPM 区块之间最顺滑的过渡
- 从深夜 R&B 切回高能 House：先用 Future Bass 做过渡，再往上走
- DnB（160+ BPM）切出时需要先降速，用 Bass House 或 Dubstep 做缓冲

**精准度要求**：用户近年从"广撒网"转向"精准深挖"，最近又进入"多线并行补番"活跃期。推荐要**命中已验证的审美**，而非泛泛丢新歌——优先从锚点艺人曲库取材，延伸方向只在合适的情绪节点尝试。**品味在扩张，不是在固化**——可以在用户已有口味的延伸方向上适度推荐新艺人。

**版本选择**：
- 对 Remix / Extended / Club Edit 接受度高（歌单约一成是这类版本），推荐时可适度使用
- 绝对不推荐 cover 翻唱版，只推荐原唱

**不推荐**：Lo-fi、纯 Ambient、纯爵士、重型摇滚、工业感强的 Neurofunk DnB（跟旋律系 DnB 完全不同，不要混淆）
