# 用户音乐品味档案

> 数据来源：网易云歌单「喜欢的音乐」5,545 首全量分析（v3.0 完整重整版，2026-06）
> 分析方法：艺人频次统计 + 专辑级归类 + 时长分布 + 版本命名模式 + 曲库知识人工归类

---

## 整体画像：五维歌单

**常见误判**：看到 Don Diablo(114)、Martin Garrix(95) 就贴"EDM 爱好者"标签——但完整排查后，明确 EDM 属性曲目仅约 **37%**，其余 **63%** 是更庞杂、更私密的音乐世界。

**正确读法**：这是一份以 **EDM 为外框、Hip-Hop 为第二支柱、R&B/流行为情绪填充、华语为第二语言、Indie/Alt 为隐藏纵深** 的五维歌单。五条线各自成体系，且有清晰的时间演变轨迹——从"广撒网探索"到"精准深挖"到最近的"多线并行补番"活跃期。**品味在扩张，不是在固化。**

## 六大圈层详解

### 圈层一：电子舞曲 EDM（~37%，外框语言）

EDM 是这份歌单的"框架语言"——你从它开始听，它提供了基调和大量数量，但不代表全部口味。

**内部子类型：**

| 子类型 | 核心艺人 | 说明 |
|---|---|---|
| ① Future House / Progressive House（最核心） | Don Diablo(114)、Martin Garrix(95)、Avicii(62)、Tiësto(59)、Armin van Buuren(53) | **Future House 是唯一可称"最爱子类型"的细分**。Don Diablo 一人 114 首无人匹敌 |
| ② Future Bass / 旋律电子（第二核心） | ILLENIUM(50)、San Holo(49)、Vicetone(72) | 和情绪系 R&B 审美重叠度高——人声驱动、情感浓度大。Vicetone 四年年度 Mix 是真实收听习惯 |
| ③ 主舞台 / Big Room / Trance | Hardwell(40)、R3HAB(48)、Calvin Harris(37)、deadmau5(37)、Yellow Claw(43) | deadmau5 的 70 分钟连续混音被完整收录——对 DJ Set 有消费兴趣 |
| ④ 热带浩室 / Chill EDM | Kygo(47)、Lost Frequencies、Sam Feldt | 松弛感，和华语独立线在情绪上互通 |
| ⑤ 当代俱乐部复兴（最新方向） | Fred again..、Knock2、ISOxo、SG Lewis | 集中在歌单最新区间，2023 年后主动追新的证据 |
| ⑥ 🆕 Drum & Bass 旋律系/Liquid（新坑） | Sub Focus(9)、Dimension(7) | 24 首全部集中在最新前 3.5%，密度独一份。和 Future Bass 审美一脉相承 |
| ⑦ 艺术电子异类 | Daft Punk(22)、Porter Robinson(20)、Madeon(12) | **把电子乐当作者性表达而非功能性消费**——Daft Punk 收整张《Random Access Memories》，Porter Robinson 专辑级深听 |

### 圈层二：Hip-Hop / Trap / Rap（~10%，最被低估的主线）

590 次命中，55 位艺人。时间分布集中在 2021–2023 区间（216 次），是所有圈层里单段最高峰——不是零散收藏，而是一段真实的深挖期。

| 子类型 | 核心艺人 | 说明 |
|---|---|---|
| ① Mainstream / 传奇级 | Post Malone(50)、Drake(35)、Kanye West(29)、Nicki Minaj(19) | **Kanye《MBDTF》被挖最深**（5 首），说明偏好"有野心的专辑"而非热单 |
| ② 艺术/意识流 | Tyler the Creator(15)、Kendrick Lamar(17) | Tyler 横跨完整风格演变弧线，《IGOR》最深（最接近 R&B/艺术电子）；Kendrick 从《good kid》到《GNX》长期追踪 |
| ③ Trap / Modern Rap | Travis Scott(23)、Future(23)、Metro Boomin(19)、21 Savage(16) | 制作感强、氛围驱动——和 EDM 的"沉浸式节拍体验"逻辑接近 |
| ④ Emo Rap | XXXTENTACION(17)、Juice WRLD | 情感浓度高、旋律性强，和 R&B 圈层交叉 |
| ⑤ 华语 + 亚裔 Hip-Hop | 马思唯(18)、法老(6)、KEY.L刘聪(7)、Joji(7)、88rising(11) | 完整的华语说唱圈选品逻辑，非随机涉猎 |

### 圈层三：R&B / Soul / Neo-Soul（~5%，情绪密度最高）

292 次命中，几乎全是独立作品（非合作 feat. 的被动消费）。

| 艺人 | 收录 | 独立作品占比 | 备注 |
|---|---|---|---|
| The Weeknd | 45 | 51% | 横跨《Starboy》→《Dawn FM》→《After Hours》，完整追过多专辑。**The Weeknd 是 R&B 口味和 Synthwave 口味的天然交汇点** |
| Khalid | 24 | 17% | 大量 feat. 但也有独立深听 |
| 陶喆 | 21 | 90% | 华语 R&B 主线 |
| SZA | 20 | 45% | 独立和合作均有 |
| HONNE | 15 | 67% | 电子灵魂乐，和 EDM 边界模糊 |
| 丁世光 | 12 | 92% | 华语 Neo-Soul，几乎全主动选曲 |
| Frank Ocean | 12 | 75% | 主动深听，非流量驱动 |
| 方大同 | 11 | 91% | 华语 R&B 老派精品 |
| 刘柏辛 Lexie | 15 | 93% | 华语 Alt-R&B |

**华语 R&B 是独立精品线**：陶喆(21)、丁世光(12)、方大同(11)、刘柏辛(15)——四位都以独立作品为主，R&B 审美在华语圈有完整版图。

### 圈层四：华语音乐（~7%，真正的第二语言）

379 次命中，横跨 7 种子类型，贯穿全时间线。各段时间主角不同，说明华语口味本身也在演变。

| 子类型 | 核心艺人 | 说明 |
|---|---|---|
| ① 华语经典 Mandopop | 周杰伦(42)、陈奕迅(17)、王力宏(9) | 周杰伦量最大且分散，是"情绪触发素材"而非某时期主力 |
| ② 华语 R&B / Soul | 陶喆(21)、方大同(11)、丁世光(12) | 主动持续深听 |
| ③ 华语 Hip-Hop | 马思唯(18)、KEY.L刘聪(7)、法老(6) | 跨 trap 到 old-school |
| ④ 华语独立 / 台湾 Indie / City Pop | 陈绮贞(12)、魏如萱(12)、落日飞车(9)、告五人(10)、甜約翰(7) | **最新发现**，集中暴力补番，和 The Marías/Grimes 同期进坑 |
| ⑤ 华语流行/都市 | G.E.M.(18)、李荣浩(10)、刘柏辛(15) | 情感表达强、制作精细 |
| ⑥ 华语独立电子 | CORSAK(4)、夏日入侵企画(8)、Panta.Q(8) | 对应 Future Bass 那条线 |
| ⑦ 华语另类/实验 | 棱镜乐队(7)、回春丹(3) | 小众触角 |

### 圈层五：Alt-Pop / Indie / 另类（~320首，隐藏纵深）

结构最复杂的一条线，横跨六种截然不同的子类型，几乎全是"主动深听的独立作品"。

| 子类型 | 核心艺人 | 说明 |
|---|---|---|
| ① Emo-Alt / 情感另类流行（最大子集 ~110首） | twenty one pilots(25)、Billie Eilish(24)、Sasha Alex Sloan(24) | **twenty one pilots 是歌单里唯一的"乐队级真爱"**——《Blurryface》(7)+《Vessel》(5)，最黑暗内省的两张 |
| ② Synthwave / Neo-80s（~41首） | The Midnight(27)、M83(14) | 小但最聚焦的子集，配合 The Weeknd《Dawn FM》可拼出完整"80s 复古合成器美学"地图 |
| ③ Art-Electronic / Hyperpop 周边（~28首） | Grimes(5)、Charli xcx(18) | Grimes 全部集中在最新 3%——"发现即密集吸收"。冷感电子 + 前卫人声 + 反流行商业逻辑 |
| ④ Dream Pop / Shoegaze 边缘（~13首，最新发现） | The Marías(12) | 全部在最新 Seg1，和陈绮贞/魏如萱同期——慵懒、氛围感优先、不强调节拍 |
| ⑤ Indie Rock / 车库（~25首） | The Strokes(14)、Tame Impala(3) | **The Strokes 8 首来自《The New Abnormal》(2020)**——不是怀旧复古粉，是被成熟近作打动 |
| ⑥ Bedroom Pop / Gen-Z 独立（~16首） | Clairo(3)、Olivia Rodrigo(8) | 轻触碰而非深挖 |

### 圈层六：主流流行 Pop（~9%，被动接受 + 主动筛选混合型）

Justin Bieber(38) 量大但多来自合作 feat.；Dua Lipa(29) + Lauv(22) + Charlie Puth(19) 是更纯粹的 Pop 审美——和 The Chainsmokers 的 EDM-Pop 跨界线本质相同。
- **隐藏线索**：Hans Zimmer(8) + John Williams(5) = 18 首电影配乐，说明对"功能性音乐/纯器乐叙事"有容量
- **Lauv(22)** 的 Indie-Pop 质感和 Sasha Alex Sloan、Phoebe Ryan 的情感创作歌手线互通

## 节奏与能量：BPM 三极分布

| 能量极 | BPM | 风格 | 说明 |
|---|---|---|---|
| 极高能 | 160–180 | 🆕 Liquid DnB（Sub Focus / Dimension） | 最新入坑，数量小但密度高 |
| 高能 | 120–135 | 主舞台 House / Progressive / Future House / Bass / Trap | 主体巡航段 |
| 中能 | 90–115 | Future Bass / Alt-R&B / Mandopop / Hip-Hop 抒情曲 | 情绪填充段 |

**时长偏好**：平均 3:42，中位数 3:28，72.7% 集中在 3–4 分钟——单曲/Radio Edit 长度，结构清晰、有记忆点、不拖沓。14 支超 10 分钟的连续 Mix 是"特定场合的完整沉浸"而非日常模式。

**纯氛围/纯器乐几乎缺席**——即使在最慢的"治愈"场景，选的也是有清晰律动的 City Pop / 独立流行，而非钢琴曲或环境音乐。

## 版本偏好

- 约 6.2% 带 "Remix"，1.7% 带 "Edit"，1.4% 带 "Extended"——合计约 **一成是 DJ/俱乐部向改编版本**
- 对 Remix / Extended / Club Edit 接受度高（这是"改编增强"而非"他人翻唱"）
- **不推荐 cover 版本**（他人翻唱），只推荐原唱

## 口味演变时间轴

| 时期 | 约对应年份 | 主要特征 |
|---|---|---|
| Seg5（最早） | ~2018 | EDM 广撒网，主流 Pop 跟随，艺人多样性极高(0.95)；王力宏/周杰伦华语入场 |
| Seg4 | ~2019–2020 | twenty one pilots 大规模深挖，周杰伦经典集中回听，Hip-Hop 初步接触 |
| Seg3 | ~2020–2022 | The Midnight 大规模补番，M83 入坑；EDM 主力但开始分化；Lexie/G.E.M. 华语线活跃 |
| Seg2 | ~2022–2024 | **Hip-Hop 最高峰**（216次）：Kanye《MBDTF》深挖，Tyler 多专辑扫，Kendrick 持续；The Strokes 集中补番；陶喆整张挖掘；多样性降至 0.78（精准回访） |
| Seg1（最新） | ~2024–2026 | **多线并行急速补番**：陈绮贞+魏如萱台湾独立线，The Marías+Grimes 梦幻/艺术线，Sub Focus+Dimension DnB 新坑，Kendrick《GNX》、Tyler《CHROMAKOPIA》紧跟 |

**最重要的规律**：歌单从"广撒网探索"向"精准深挖"演变，近两年进入"多条新线同时密集补番"的活跃期——既在往更快（DnB）走，也在往更慢更氛围（台湾独立/梦幻流行）走，同时继续跟进 Hip-Hop 前沿。**品味在扩张，不是在固化。**

## 关键审美线索（区别于普通泛听的指标）

以下线索说明用户的审美比数字表面更深：

- **EDM 内**：Porter Robinson / Daft Punk = 把电子乐当作品性表达而非功能性消费
- **Hip-Hop 内**：Kanye《MBDTF》+ Tyler《IGOR》= 偏好"有野心的专辑"而非热单
- **Alt/Indie 内**：twenty one pilots《Blurryface/Vessel》= 内省、歌词驱动的另类摇滚真爱
- **The Strokes** 迷的是《The New Abnormal》不是《Is This It》= 成熟品位，非复古情怀
- **The Weeknd** 跟到《Dawn FM》= 欣赏艺术演变，非只消费热单

## 不喜欢 / 慎用

- **绝对避免**：heavy metal / 极端金属、土嗨 DJ 串烧、现场嘈杂录音版本
- **几乎不存在**：Lo-fi、纯 Ambient、极简氛围、古典钢琴曲、纯爵士——偶有出现但属孤例
- **工业感强的 Neurofunk / Jungle**：与旋律系 DnB 完全不同，不要混淆
- **翻唱版（cover）**：不推荐，除非用户明确要求
